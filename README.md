# Tuotepäällikkö · Cleor Oy

Cleor Oy toimittaa uudis- ja korjausrakentamiseen tilavarusteet, kuten annostelijat, peilit, esteettömyysvarusteet, tuulikaappimatot ja ilmoitustaulutuotteet. Hoidamme kohteen avaimet käteen -periaatteella: tuotevalinnat, hankinnan, työmaalogistiikan ja asennukset.

Tuotteiden takana on pääosin oma tytäryhtiömme Hani-Tuote Oy, joka on hankinta-, varasto- ja tuotetalo. Hani-Tuote toimittaa tuotteita myös rakennustarvikeliikkeille ja tukuille sekä verkkokaupassa hani.fi.

Vuonna 2018 Seinäjoella perustettu Cleor on kasvanut kannattavasti perustamisestaan saakka, ja kehitämme toimintaamme jatkuvasti myös omilla digitaalisilla työkaluillamme.

Haemme uuteen perustettavaan tehtävään tuotepäällikköä kasvavaan konserniimme vastaamaan Hani-Tuote Oy:n valikoimasta sekä Cleor Oy:n projektimyynnin tuotevalikoimasta.

Hakemus tulee palauttaa ohjeistuksen mukaisesti **22.11.2026 mennessä**.

Tämän rekrytoinnin ensimmäinen vaihe on suunniteltu tekoälyn kanssa käytäväksi keskusteluksi. Keskustelun lähtökohtana on tämän sivun osoite ja `AGENTS.md`-tiedoston lukeminen.
